# CP1404 Assignment 1: Travel Tracker
## Author
Qiuhao Wu

## Description
A simple Python program to manage a list of travel places, including functions to:
- Load/save place data from/to a CSV file (`places.csv`)
- Display places sorted by visit status (unvisited first) and priority
- Add new places with validation
- Recommend a random unvisited place
- Mark places as visited

## How to Run
1. Ensure you have Python 3.x installed.
2. Clone this repository to your local machine.
3. Run the program with:
   ```bash
   python assignment1.py
