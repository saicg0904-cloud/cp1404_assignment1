## Description
A simple Python program to manage a list of travel places, following CP1404 assignment requirements. The program supports loading/saving data from/to CSV, displaying sorted places with dynamic column alignment, adding new places with input validation, recommending random unvisited places, and marking places as visited by index (precise matching).

## Files
- `assignment1.py`: Main program file with all core functions (load/save, display, add, recommend, mark visited)
- `places.csv`: CSV file to store place data (name, country, priority, visited status)
